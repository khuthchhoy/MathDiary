ប្រធាន

  1. គណនាអាំងតេក្រាលខាងក្រោម៖
    1. $\displaystyle\int _{0}^{3}\dfrac{4}{2x+3}\,dx$
    2. $\displaystyle\int _{0}^{1}\dfrac{9}{(2x+1)^2}\,dx$
    3. $\displaystyle\int _{e}^{3}\dfrac{1}{x\ln x}\,dx$
    4. $\displaystyle\int _{-1}^{1}\dfrac{e^x}{e^x+1}\,dx$
  2. គេមាន$f(x)=\dfrac{5x+13}{(2x+1)(x+4)}$។
    1. រកចំនួនពិត$A$ និង$B$ដែល$f(x)=\dfrac{A}{2x+1}+\dfrac{B}{x+4}$។
    2. គណនា$\displaystyle\int_{0}^{4} f(x)\,dx$។
  3. គេមានអនុគមន៍$f$កំណត់លើ$\mathbb{R}$ដោយ$f(x)=\dfrac{4(2x+1)}{x^2+2}$ មានក្រាបតាងដោយ$C$ក្នុងតម្រុយអរតូណរមេ។
    1. គណនា$f'(x)$។
    2. សិក្សាអថេរភាពនៃ$f$ រួចសង់តារាងអថេរភាពនៃ$f$។
    3. រកសមីការបន្ទាត់$T$ ប៉ះនឹងក្រាប$C$ត្រង់ចំណុច$A$មានអាប់ស៊ីស$4$។
    4. សង់ក្រាប$C$និងបន្ទាត់$T$។
