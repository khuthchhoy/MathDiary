  1. គណនាលីមីតខាងក្រោម៖
    1. $\lim\limits_{x\to +\infty}\dfrac{3x-4x^2}{2x^2+3x+4}$
    2. $\lim\limits_{x\to -\infty}\dfrac{x^2-x+1}{2x^2-5}$
    3. $\lim\limits_{x\to e}\left[(\ln x)^2-\ln x+3 \right]$
    4. $\lim\limits_{x\to -3}\dfrac{\sqrt{x^2+7}-4}{x+3}$
    5. $\lim\limits_{x\to 4}\dfrac{x-4}{\sqrt{x}-2}$
  2. គណនាអាំងតេក្រាលខាងក្រោម
    1. $\displaystyle\int_2 ^7 (2x-8)\,dx$
    2. $\displaystyle\int_{-1} ^3 (4-5x)\,dx$
    3. $\displaystyle\int_{\ln 2} ^3 5e^x\,dx$
  3. គេមានអនុគមន៍$f$ដែល$f(x)=\dfrac{x^2+3x+6}{x+1}$ និងមានក្រាបតាងដោយ$C$។
    1. រកដែនកំណត់នៃអនុគមន៍$f$។
    2. បង្ហាញថា$f(x)=x+2+\dfrac{4}{x+1}$។
    3. រកសមីការអាស៊ីមតូតឈរ និងទ្រេតនៃក្រាប$C$។
    4. សិក្សាអថេរភាពនិងសង់ក្រាប$C$នៃអនុគមន៍$f$។
