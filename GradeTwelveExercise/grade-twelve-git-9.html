ប្រធាន

  1. គណនាលីមីតខាងក្រោម៖
    1. $\displaystyle\lim_{x\to 1}\dfrac{2x^2-5x+3}{x^2+6x-7}$
    2. $\displaystyle\lim_{x\to 0}\dfrac{\sqrt{x+4}-2}{\sin 5x}$
    3. $\displaystyle\lim_{x\to +\infty}\left( e^x-7x+6\right)$
    4. $\displaystyle\lim_{x\to +\infty}\dfrac{e^x+1}{e^x-1}$
  2. គណនាអាំងតេក្រាលខាងក្រោម៖
    1. $\displaystyle\int_{-1}^{1}\left(x^2-1\right) \,dx$
    2. $\displaystyle\int_{1}^{2}\left(\frac{3}{x^2}-2\right) \,dx$
  3. គេមានសមីការ$4x^2+(y+2)^2=4$។ ចូរបង្ហាញថាសមីការនេះជាអេលីប រួចរកកូអរដោនេនៃផ្ចិត កំពូលទាំងពីរ និងកំណុំទាំងពីរ រួចសង់អេលីបនេះ។
  4. ក្នុងថង់មួយមានអក្សរ$10$តួ a, b, c, d, e, f, g, h, i, j ។ គេចាប់យកអក្សរ4តួព្រមគ្នាចេញពីថង់ដោយចៃដន្យ។ រកប្រូបាបនៃព្រឹត្តិការណ៍៖
    A: គ្មានស្រៈមួយសោះ។
    B: បានស្រៈតែមួយគត់។
    C: បានស្រៈតែ2គត់។
    D: យ៉ាងតិចណាស់បានស្រៈមួយ។
  5. គេមានអនុគមន៍$f$កំណត់ដោយ$f(x)=\dfrac{4x^2-8x+7}{1-2x}$ មានក្រាប$(C)$ក្នុងតម្រុយអរតូណរម៉ាល់$\left(O,\vec{i},\vec{j}\right)$។
    1. ចូររកដែនកំណត់នៃអនុគមន៍$f$។
    2. រកតម្លៃនៃចំនួនពិត$a$, $b$ និង$c$ដែល$f(x)=ax+b+\dfrac{c}{1-2x}$។
    3. គណនាលីមីតនៃ$f(x)$ ត្រង់$-\infty$, $+\infty$, ${\dfrac{1}{2}}^{-}$ និង${\dfrac{1}{2}}^{+}$។ ទាញរកអាស៊ីមតូតឈរនៃក្រាប$(C)។
    4. បង្ហាញថាបន្ទាត់$y=-2x+3$ជាអាស៊ីមតូតទ្រេតនៃក្រាប$(C)$។
    5. សិក្សាអថេរភាពនៃ$f$ និងសង់ក្រាប$(C)$។
