    2. $\lim\limits_{x\to +\infty}\dfrac{1}{e^x-1}$
    3. $\lim\limits_{x\to 0}\dfrac{e^x+x-3}{e^x+2}$
  2. គណនាអាំងតេក្រាលខាងក្រោម៖
    1. $\displaystyle\int _1 ^2 x\left( x^2-3\right)\,dx$
  3. គេមានសមីការ$(E): 4(x-3)^2+9(y-2)^2=36$។ បង្ហាញថាសមីការ$(E)$គឺជាសមីការអេលីប រួចកំណត់កូអរដោនេនៃផ្ចិត កំពូល កំណុំ ហើងសង់អេលីបនេះ។
  4. គេមានអនុគមន៍$f$ កំណត់ដោយ$f(x)=\dfrac{x^2+3x+3}{x+1}$។ តាង$C$ក្រាបនៃ$f$ក្នុងតម្រុយអរតូណរមេ$\left(O,\vec{i},\vec{j} \right)$។
    1. ចូររកតម្លៃនៃចំនួនពិត$a,b,c$ ដែល$x\ne 1$, $f(x)=ax+b+\dfrac{c}{x+1}$។
    2. សិក្សាអថេរភាពនៃ$f$ និងរកចំណុចអតិបរមា ឬអប្បបរមានៃ$C$។
    3. គណនាលីមីតត្រង់ចុងដែនកំណត់នៃ$f(x)$។ ទាញរកសមីការអាស៊ីមតូតឈរនៃក្រាប$C$។
    4. បង្ហាញថា$\lim\limits_{x\to \pm\infty}\bigl[f(x)-()\bigr]=0$។ ទាញរកសមីការអាស៊ីមតូតទ្រេតនៃក្រាប$C$។
    5. ចូរសិក្សាទីតាំងធៀបរវាងក្រាប$C$ និងបន្ទាត់$D: y=x+2$
    6. ចូរសង់តារាងអថេរភាពនៃ$f$ រួចសង់ក្រាប$C$។
