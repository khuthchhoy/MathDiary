  1. $L_1$ជាបន្ទាត់កាត់តាមចំណុច$(1,1)$ និងមានវ៉ិចទ័រប្រាប់ទិស$\vec{u}_1=(1,2)$ ហើយ$L_2$ជាបន្ទាត់កាត់តាមចំណុច$(1,5)$ និងមានវ៉ិចទ័រប្រាប់ទិស$\vec{u}_2=(3,-4)$។
    1. រកសមីការប៉ារ៉ាម៉ែត្រនៃបន្ទាត់$L_1$និង$L_2$ដែលមានប៉ារ៉ាម៉ែត្រ$s$និង$t$រៀងគ្នា។
    2. រកកូអរដោនេនៃចំណុច$L_1$និង$L_2$។
  2. ចូរបង្ហាញថា បន្ទាត់$x=1$ជាអ័ក្សឆ្លុះនៃប៉ារ៉ាបូល$y=2x^2-4x+5$។
  3. ចូរបង្ហាញថា ចំណុច$I(2,1)$ជាផ្ចិតឆ្លុះនៃក្រាបតាងអនុគមន៍$y=\dfrac{x}{x-2}$។
  4. គេមានអនុគមន៍$f$កំណត់ដោយ$f(x)=\dfrac{x}{x-1}។
    1. ចូរសរសេរ$f(x)$ជារាង$f(x)=\dfrac{k}{x-\alpha}+\beta$ដែល$k,\,\alpha~\text{និង}~\beta\in\mathbb{R}$។
    2. សង់ក្រាប$C_f$ក្នុងតម្រុយកូអរដោនេ។
    3. គេមានបន្ទាត់$d:y=m-x$។ ចូររកតម្លៃ$m$ដើម្បីឱ្យសមីការ$f(x)=m-x$មានឫសពីរជាចំនួនពិតផ្សេងគ្នា។
  5. គេមានអនុគមន៍$f$ និង$g$កំណត់ដោយ$f(x)=\dfrac{-x+1}{x+1}$ និង$g(x)=x^2+2x-3$ មានក្រាបតាងដោយ$C_f$និង$C_g$។
    1. ចូរសិក្សាសញ្ញានៃពហុធា$P(x)=x^3+3x^2-4$។
    2. រកកូអរដោនេនៃចំណុចប្រសព្វរវាងក្រាប$C_f$ និង$C_g$។
    3. សិក្សាសញ្ញានៃ$f(x)-g(x)$។ តើគេអាចនិយាយដូចម្ដេចចំពោះក្រាប$C_f$និង$C_g$?
    4. សរសេរ$f(x)$ជារាង$f(x)=\dfrac{k}{x-\alpha}+\beta$ដែល$k,\,\alpha~\text{និង}~\beta\in\mathbb{R}$។
    5. សរសេរ$g(x)$ជារាង$g(x)=a(x-p)^2+q$។
    6. សង់$C_f$និង$C_g$។
