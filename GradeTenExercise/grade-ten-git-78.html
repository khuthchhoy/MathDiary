  1. រកអនុគមន៍ច្រាសនៃអនុគមន៍ខាងក្រោម៖
    1. $f(x) = 1 - 3x$
    2. $f(x) = 4 - \dfrac{3}{2}x$
    3. $f(x) = 7 - x^3$
    4. $f(x) = \dfrac{1}{x}$
    5. $f(x) = \dfrac{3}{x - 1}$
    6. $f(x) = -\dfrac{2}{x + 1}$
    7. $f(x) = \dfrac{x}{x - 1}$
    8. $f(x) = \dfrac{x + 1}{x + 2}$
    9. $f(x) = x^2$, $x \gt 0$
    10. $f(x) = x^2 + 2$
    11. $f(x) = \sqrt{x + 5}$
  2. ចូរបង្ហាញសមភាពខាងក្រោម៖
    1. $\dfrac{\sin x - \sin x \cos x}{\cos x - \big( 1 - \sin^2 x \big)} = \tan^2 x$
    2. $\dfrac{1}{1 + \sin x} + \dfrac{1}{1 - \sin x} = \dfrac{2}{\cos^2 x}$
