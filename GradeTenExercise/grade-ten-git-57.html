ប្រធាន

  1. រកតម្លៃនៃចំនួនពិត$x$ និង$y$ដើម្បីឱ្យ៖
    1. $3+5i+x-yi=6-2i$
    2. $x+yi=(1-i)(2+8i)$
    3. $\dfrac{x}{i+i}+\dfrac{y}{1-2i}=1$
    4. $\dfrac{x}{2-i}+\dfrac{yi}{i+3}=\dfrac{2}{1+i}$
  2. ចូររកចំនួនកុំផ្លិច$z$ដែលផ្ទៀងផ្ទាត់$z(3+3i)=2-i$ ។
  3. ចូរដោះស្រាយសមីការ៖
    1. $\dfrac{x}{x-6}+\dfrac{x}{x+2}=\dfrac{2}{15}$
    2. $\dfrac{1}{x}+\dfrac{x}{x+2}=\dfrac{5}{3}$
    3. $\dfrac{x}{x+2}-\dfrac{x-1}{x}=4$
    4. $\dfrac{1}{2x+3}+\dfrac{1}{6-x}=\dfrac{2}{5}$
  4. ដោះស្រាយវិសមីការ៖
    1. $\dfrac{2x+3}{x-1}\le\dfrac{4x}{2x-3}$
    2. $\dfrac{7-x}{x+1}\gt\dfrac{4-x}{x+3}$
  5. គេមានសមីការ$(E):x^2+y^2+6x-2y+6=0$ ។
    1. ចូរបង្ហាញថាសមីការ$(E)$ជាសមីការរង្វង់ រួចកំណត់កូអរដោនេនៃផ្ចិត និងកាំនៃរង្វង់នេះ ។
    2. សង់រង្វង់$(E)$ក្នុងតម្រុយកូអរដោនេ ។
  6. គេមានអនុគមន៍$f$កំណត់ដោយ$f(x)=\dfrac{4x-10}{2x+5}$ មានក្រាប$(C)$ក្នុងតម្រុយកូអរដោនេ ។
    1. រកដែនកំណត់នៃអនុគមន៍$f$ ។
    2. រកចំនួនពិត$a,\,p$ និង$q$ដើម្បីឱ្យ$f(x)=\dfrac{a}{x-p}+q$ ។
    3. រកសមីការអាស៊ីមតូតទាំងអស់នៃក្រាប$(C)$ ។
    4. រកកូអរដោនេនៃចំណុចប្រសព្វរវាងក្រាប$(C)$ និងអ័ក្សកូអរដោនេ ។
    5. សង់ក្រាប$(C)$នៅក្នុងតម្រុយកូអរដោនេ ។
