  1. រកកូអរដោនេនៃចំណុចប្រសព្វរវាងបន្ទាត់ និងប៉ារ៉ាបូលខាងក្រោម៖
    1. $y=x^2+6x$ និង$y=x-4$
    2. $y=2(x-1)^2+2$ និង$y=x+2$
    3. $y=\dfrac{1}{2}x^2+4x-2$ និង$y=x+3$
    4. $y=\dfrac{1}{2}x^2-2x-3$ និង$y=-3x+1$
  2. គេមានបន្ទាត់មានសមីការ$y=4x+k$ និងប៉ារ៉ាបូល$y=\dfrac{1}{2}x^2+2x-8$ ។ ចូររកតម្លៃ$k$ដើម្បីឱ្យ៖
    1. បន្ទាត់កាត់ប៉ារ៉ាបូលបានពីរចំណុច ។
    2. បន្ទាត់ប៉ះប៉ារ៉ាបូល ។
    3. បន្ទាត់ និងប៉ារ៉ាបូលគ្មានចំណុចប្រសព្វ ។
  3. គេមានប៉ារ៉ាបូល$y=kx^2-5x+2$ និងបន្ទាត់$y=-3x+4$ ។ ចូររកតម្លៃ$k$ដើម្បីឱ្យ៖
    1. បន្ទាត់កាត់ប៉ារ៉ាបូលបានពីរចំណុច ។
    2. បន្ទាត់ប៉ះប៉ារ៉ាបូល ។
    3. បន្ទាត់ និងប៉ារ៉ាបូលគ្មានចំណុចប្រសព្វ ។
  4. ចូរបង្ហាញសមភាពខាងក្រោម៖
    1. $\dfrac{1-2\cos^2 a}{\sin a\cos a}=\tan a-\cot a$
    2. $\dfrac{\tan\alpha+\tan\beta}{\cot\alpha+\cot\alpha}=\tan\alpha\tan\beta$
    3. $\dfrac{1-\cot\alpha}{1+\cot\alpha}=\dfrac{\tan\alpha-1}{\tan\alpha+1}$
    4. $\cos\alpha\left(\tan\alpha+\cot\alpha \right)=\dfrac{1}{\sin\alpha}$
  5. បើ$ABC$ជាត្រីកោណកែងសមបាតមានប្រវែងជ្រុង$a=b$ ចូរបង្ហាញថា$c^2=2a^2\left(1-\cos C \right)$
  6. ចូរបង្ហាញថាចំពោះគ្រប់ត្រីកោណ$ABC$គេបាន$\dfrac{\cos A}{a}+\dfrac{\cos B}{b}+\dfrac{\cos C}{c}=\dfrac{a^2+b^2+c^2}{2abc}$
  7. ចូរកំណត់តម្លៃ$k$ដើម្បីឱ្យពហុធា$P(x)=x^3-4x^2-7x+k$ចែកដាច់នឹង$x-1$ រួចដោះស្រាយសមីការ$P(x)=0$ទៅតាមតម្លៃ$k$នោះ ។
