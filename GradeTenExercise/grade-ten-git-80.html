  1. បើ$z=1+2i$ ចូររកជាទម្រង់ពីជគណិតនៃ៖
    1. $z^2$
    2. $\dfrac{1}{z}$
    3. $\dfrac{1}{z^2}$
  2. ចូរបង្ហាញសមភាពខាងក្រោម៖
    1. $\sqrt{ \dfrac{1-\sin a}{1+\sin a} } = \dfrac{\cos a}{1+\sin a}$
    2. $\cos^4 a - \sin^4 a = 1 - 2\sin^2 a$
    3. $\tan 7^\circ \tan 23^\circ \tan 67^\circ \tan 83^\circ = 1$
    4. $\sin (50^\circ + \theta) - \cos (40^\circ - \theta) = 0$
  3. បើ$\tan^4 x + \tan^2 x = 1$ ចូរបង្ហាញថា$\cos^4 x + \cos^2 x = 1$។
  4. រកតម្លៃនៃចំនួនពិត$x$ និង$y$ដែល៖
    1. $\dfrac{x}{1+i} + \dfrac{y}{1-2i} = 1$
    2. $\dfrac{x}{2-i} + \dfrac{yi}{i+3} = \dfrac{2}{1+i}$
  5. គេមានអនុគមន៍$f(x) = (3p-2)x^2 + 8x + p$, $p \ne \dfrac{2}{3}$ មានក្រាបជាប៉ារ៉ាបូល ។ ចូររកតម្លៃ$p$តាមករណីខាងក្រោម៖
    1. ប៉ារ៉ាបូលបែរភាបផតឡើងលើ និងកាត់អ័ក្សអាប់ស៊ីសត្រង់ពីរចំណុចផ្សេងគ្នា។
    2. ប៉ារ៉ាបូលបែរភាពផតឡើងលើ និងមានកំពូលលើអ័ក្សអាប់ស៊ីស ។
    3. ប៉ារ៉ាបូលបែរភាពផតឡើងលើ និងមិនកាត់អ័ក្សអាប់ស៊ីស ។
  6. គេមានចំណុច$A(-1,3)$, $B(3,1)$ និង$C(5,5)$ស្ថិតក្នុងតម្រុយអរតូណរមេ$(O,\vec{i},\vec{j})$ ។
    1. ចូររកវ៉ិចទ័រ$\overrightarrow{AB}$, $\overrightarrow{AC}$ និង$\overrightarrow{BC}$ ជាអនុគមន៍នៃវ៉ិចទ័រឯកតា។
    2. រកវ៉ិចទ័រ$\overrightarrow{OM}$ ដែល$M$ជាចំណុចកណ្ដាលនៃវ៉ិចទ័រ$\overrightarrow{AC}$។
    3. គណនា$\overrightarrow{BA}\cdot \overrightarrow{BC}$ រួចទាញបញ្ជាក់ថា$ABC$ជាត្រីកោណកែងសមបាត។
    4. រកសមីការប៉ារ៉ាម៉ែត្រនៃបន្ទាត់$L$កាត់តាមចំណុច$B$ហើយស្របនឹងវ៉ិចទ័រ$\overrightarrow{OM}$។ តើចំណុច$C$ស្ថិតនោលើបន្ទាត់$L$ឬទេ?
    5. ចូរបង្ហាញថា$OBCM$ជាប្រលេឡូក្រាម ។
