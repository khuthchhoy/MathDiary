ប្រធាន

  1. ចូរបង្ហាញសមភាពខាងក្រោម៖
    1. $\sqrt{ \dfrac{1-\sin a}{1+\sin a} } = \dfrac{\cos a}{1+\sin a}$
    2. $\cos^4 a - \sin^4 a = 1 - 2\sin^2 a$
    3. $\tan 7^\circ \tan 23^\circ \tan 67^\circ \tan 83^\circ = 1$
    4. $\sin (50^\circ + \theta) - \cos (40^\circ - \theta) = 0$
  2. បើ$\tan^4 x + \tan^2 x = 1$ ចូរបង្ហាញថា$\cos^4 x + \cos^2 x = 1$។
  3. រកតម្លៃនៃចំនួនពិត$x$ និង$y$ដែល៖
    1. $\dfrac{x}{1+i} + \dfrac{y}{1-2i} = 1$
    2. $\dfrac{x}{2-i} + \dfrac{yi}{i+3} = \dfrac{2}{1+i}$
