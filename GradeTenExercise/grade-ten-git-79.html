  2. ដោះស្រាយសមីការ៖

  3. គេឱ្យកន្សោម$p(x)=\big(\dfrac{x^2-2x}{x^2-4}-\dfrac{2}{x+2} \big)\div \dfrac{x-4}{x+2}$។
    1. សម្រួល$p(x)$។
    2. រកតម្លៃ$x$ដែលនាំឱ្យ$p(x)\lt 0$។
  4. គេមានរង្វង់$(E)$ដែលមានសមីការ$(x-5)^2+(y-4)^2=20$។
    1. ចូរកំណត់កូអរដោនេនៃផ្ចិត និងកាំនៃរង្វង់$(E)$ ។
    2. ចូររកសមីការទូទៅនៃរង្វង់$(E)$ ។
    3. ចូរបង្ហាញថា បន្ទាត់$(\Delta):\,y=2x+4$ប៉ះនឹងរង្វង់$(E)$ រួចរកកូអរដោនេនៃចំណុចប៉ះនេះ ។
  5. គេមានចំណុច$A(5,3),$ $B(3,-1)$ និង$C(p,q)$។
    1. រកកូអរដោនេនៃវ៉ិចទ័រ$\overrightarrow{AB}$ និង$\overrightarrow{AC}$ និងប្រវែងរបស់វានិមួយៗ ។
    2. គណនា$\overrightarrow{AB}\cdot\overrightarrow{AC}$។
    3. រកតម្លៃ$p$ និង$q$ដើម្បីឱ្យ$ABC$ជាត្រីកោណកែងសមបាតកំពូល$A$។
    4. រកសមីការប៉ារ៉ាម៉ែត្រនៃបន្ទាត់$AB$ រួចរកចំណុចប្រសព្វរវាងបន្ទាត់$AB$ជាមួយអ័ក្សអរដោនេ ។
  6. គេមានសមីការប៉ារ៉ាបូល$y=2x^2-4x$។
    1. ចូរសរសេរសមីការប៉ារ៉ាបូលជារាង$y=a(x-h)^2+k$ និង$(x-h)^2=4p(y-k)$។
    2. រកកូអរដោនេនៃកំពូល និងសមីការអ័ក្សឆ្លុះនៃប៉ារ៉ាបូល ។
    3. បង្ហាញថាបន្ទាត់$(\Delta):\,y=8x-18$ប៉ះនឹងប៉ារ៉ាបូល រួចរកកូអរដោនេនៃចំណុចប៉ះនេះ ។
    4. រកចំណុចប្រសព្វរវាងប៉ារ៉ាបូលនិងអ័ក្សរកូអរដោនេ។
    5. សង់ប៉ារ៉ាបូល និងបន្ទាត់$(\Delta)$ក្នុងតម្រុយកូអរដោនេ។
