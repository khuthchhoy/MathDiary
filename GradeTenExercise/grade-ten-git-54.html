  2. គេមានអនុគមន៍$f$កំណត់ដោយ$f(x)=\dfrac{2x-1}{x-1}$។
    1. ចូររកដែនកំណត់នៃអនុគមន៍$f$។
    2. រកតម្លៃ$a$, $p$ និង$q$ដែល$f(x)=\dfrac{a}{x-p}+q$។
    3. រកសមីការអាស៊ីមតូតនៃក្រាបតាងអនុគមន៍$f$។
    4. រកចំណុចប្រសព្វរវាងក្រាបនៃ$f$និងអ័ក្សកូអរដោនេ។
    5. សង់ក្រាបនៃអនុគមន៍$f$។
